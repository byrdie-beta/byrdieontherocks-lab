Project Overview

This project explores how Python can automate a newsletter campaign, from retrieving client information to sending personalized HTML emails through the Gmail API.

I built a simulated website launch campaign for ByrdieOnTheRocks, using Google Sheets as the contact database and Python to manage recipient eligibility, personalization, sending, and status updates.

Newsletter links contain dynamic UTM parameters, allowing campaign traffic to be tracked in GA4.

What I Wanted to Build

  • Retrieve client information automatically using Google Sheets API.
  • Create a reusable, personalized HTML newsletter.
  • Apply recipient eligibility rules before sending.
  • Send personalized emails through Gmail API.
  • Automatically update sending statuses in Google Sheets.
  • Track newsletter campaign traffic using GA4.

Workflow

The project connects Google Sheets, Python, and Gmail API into one newsletter automation workflow.

Google Sheets → Python → Eligibility Check → HTML Personalization → Gmail API → Status Update

Python retrieves client records, checks eligibility, and generates personalized newsletters using information stored in Google Sheets.

Gmail API sends the prepared message, and Python updates the corresponding status. Newsletter links direct recipients to the website, where UTM parameters support GA4 campaign tracking.

Newsletter automation workflow from contact retrieval to personalized email delivery and campaign tracking.

Approach

  1. Connected Python to Google Sheets API using OAuth 2.0.
  2. Retrieved client names, email addresses, sending preferences, statuses, and UTM parameters.
  3. Created a branded HTML newsletter template with dynamic placeholders.
  4. Applied eligibility rules to identify recipients marked Y and Pending.
  5. Personalized email content and subject lines using client information.
  6. Integrated Gmail API to send HTML newsletters.
  7. Updated email statuses in Google Sheets after sending requests.
  8. Verified UTM campaign traffic using GA4.

Email Eligibility & Status Tracking

The automation processes recipients only when sendEmail = Y and status = Pending.

After Gmail accepts a sending request, Python updates the status to Sent. Records already marked Sent are skipped on later runs.

Sending errors follow a separate handling path. Additional duplicate-prevention safeguards are planned for future development.

Testing used sample contact records and controlled email accounts. The public project version excludes private credentials, tokens, and client information.
